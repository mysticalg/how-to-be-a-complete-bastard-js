How to Be a Complete Bastard

1987 · Virgin Games · Sentient Software

Controller: press a pad button to connect.

Controls & help

Pad: stick / D-pad move or select · A confirm · B back · X pockets · Y fart · LB / RB rotate · LT sound · Start pause · Select reset · L3 view · R3 art.

Touch: use the arrows to move or select, then Action / Confirm. Hold a direction and Action together to interact while walking. Back returns through menus. Pockets opens inventory. Take, use and empty-pocket actions are chosen in the game menus when available.

Keyboard fallback: Q/A/O/P or arrows · Space/Enter confirm · I pockets · F fart · 1/2 rotate · Esc back/pause · R reset · V view · M art.

About this reconstruction

A native JavaScript reconstruction with guest behaviour, item effects, scoring, ratings and endings. Photoreal Isometric covers all fourteen rooms; Original Split remains available. The isometric architecture and generated appearances are interpretations of the recovered layouts. Verification coverage and sound/timing limitations are documented.
